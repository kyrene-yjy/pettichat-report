04

CTA：全链路只有一句 "link in my bio"

42 条 TikTok 视频中 22 条 caption 含该句，画面内 CTA 与之相同，没有第二层承接。

现状

单一 bio link；无评论区关键词、无优惠码、无多语言 CTA、无主页置顶承接。头部 584K 视频同样只有 bio link。

断点

Instagram 侧 193 条"求链接 / 问价"评论只有 11 条得到官方回复（5.7%）；TikTok 侧 reseller 用 WhatsApp 承接，品牌号基本不回复。

93% 的播放没有被任何转化路径接住——CTA 不是"不够显眼"，而是只有一层。
05

可复用的 12–15 秒结构

头部 5 条全部符合该节奏；偏离结构的长视频适合做信任内容，不适合拉新。
0–2s荒诞钩子：一句宠物台词，制造"它在说话"的错觉
2–8s台词 2–3 句，情绪递进：害怕→求救 / 黏人→争宠
8–11s反转：主人反应或第三句台词
11–13s产品名 + 一句功能（全片唯一一次）
13–15sCTA：口播 + 字幕 + 评论区关键词
06

平台差异

同一素材，两种分发逻辑。

TikTok

  • 官方账号（pettichat.shorts / pettichatuk / pettichatofficial）英文 + zh-Hans 译制字幕分发。
  • es / ja / ru 由 reseller 本地化承接，形成"官方素材 → 本地渠道"的分层。
  • 字幕自带率高（63%），是低成本内容分析的优势平台。

Instagram

  • 官方 reels 12–37 秒英语，评论问链接占比 59%，官方 0 回复。
  • 流量最高的是 reseller / 创作者（789K 播放、17.5K 赞）。
  • 无字幕接口，逐字稿需 ASR；评论 API 分页不稳定。
07

建议（按优先级）

  1. 每月 2–3 条荒诞情景剧新设定；同一剧本不要多号复投（实测 584K → 45K → 4.4K → 74）。
  2. 前 3 秒永远不放产品，产品名全片只出现一次。
  3. CTA 升级为三件套：视频内口播 + 评论区置顶关键词 + 主页链接；每个语言版本配本地化 CTA。
  4. 评论区 24 小时内回复：问链接/问价占 59%，目前品牌号几乎不回复。
  5. 本地化交给 reseller，但给统一素材包（台词模板 + 字幕文件 + 一句话卖点），避免长测评拉低自然流量。
  6. 时长控制在 12–15 秒；测评类单独做长视频，不混入拉新投放。
